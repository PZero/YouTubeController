description: Salva lo stato della sessione nei documenti del progetto
---

Chiudiamo la sessione. Senza rileggere file che non servono:

1. Aggiorna `docs/STATO.md`: data di oggi, fase attuale, cosa è stato fatto in questa sessione, prossimi passi, problemi aperti. **Riscrivi** il file tenendolo sotto le 60 righe: è una fotografia dello stato, non un diario.
2. Aggiungi a `docs/DECISIONI.md` le decisioni prese oggi (data, decisione, una riga di motivazione). Non riscrivere quelle vecchie.
3. Se sono cambiati componenti o misure, verifica che `docs/BOM.md` ed `enclosure/dimensioni.md` siano allineati.
4. Aggiorna il `README.md` principale (vetrina del repository su GitHub) se sono cambiati stato, funzioni, tasti/gesti, componenti, foto (`docs/foto/`, senza metadati EXIF/GPS) o render (`docs/render/`). Solo sintesi e link ai documenti di dettaglio.
5. Prima del commit controlla che nei file non ci siano chiavi, token o password.
6. Se la cartella è un repository git, fai un commit con un messaggio che riassume la sessione.
7. Rispondimi con 5 righe al massimo: cosa è stato salvato e da dove ripartire la prossima volta.

Dopo questo comando posso chiudere la chat o usare `/clear`.
